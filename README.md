# Division

Division は、macOS のデスクトップ（Mission Control スペース）ごとにウィンドウをカラム分割し、ホットキーで配置・フォーカス移動・番号切替ができるメニューバー常駐ツールです。

## 主な機能

- デスクトップごとにレイアウトを選択（1:1 / 1:2 / 2:1 / 1:1:1）
- 標準ウィンドウを現在のスペースで管理し、中心座標からペインへ自動割り当て
- ホットキーでペイン間のフォーカス移動とウィンドウ移動（事前の参加操作は不要）
- フローティングスイッチャーで、**今いるペイン内**のウィンドウを番号入力して切替・ドラッグ並べ替え。未割り当てのウィンドウも同じリストから選べる
- 新規ウィンドウを、直前にフォーカスしていたウィンドウのペインへ自動割り当て

## 動作環境

- macOS 14 以降
- アクセシビリティ権限（ウィンドウの移動・前面化に必要）

## インストール

ソースからビルドする場合:

```sh
Scripts/build-app.sh
open dist/Division.app
```

アプリは `dist/Division.app` に生成されます。バンドル ID は `com.boke0.division` で、ad hoc 署名を施します。

ad hoc 署名のため Notarization は行っていません。macOS に初回起動を止められた場合は、Finder で `Division.app` を右クリックし、ショートカットメニューから「開く」を選択してください。

Division は起動後もメニューバーに常駐し、Dock には表示されません。

開発中のパッケージテストは次のコマンドで実行できます。

```sh
swift test
```

## 権限

初回起動時に、アクセシビリティ権限の許可を求めます。システム設定の「プライバシーとセキュリティ > アクセシビリティ」で Division を有効にしてください。権限がないと、ウィンドウの移動・リサイズ・前面化は動作しません。

## 基本操作

デフォルトの修飾キーは `cmd+opt` です。

| 操作 | デフォルト |
| --- | --- |
| 左/下/上/右のペインへフォーカス | `cmd+opt+h` / `j` / `k` / `l` |
| フォーカス中ウィンドウをその方向のペインへ移動 | `cmd+opt+shift+h` / `j` / `k` / `l` |
| レイアウトを循環 | `cmd+opt+tab` |
| スイッチャーを開く | `opt+tab` |

タイル配置・スペース切替・新規ウィンドウ・スイッチャー表示のタイミングで、現在のスペース上の標準ウィンドウを列挙します（Division 自身の UI やパレットなどは除く）。スペース切替時、まだ割り当てのないウィンドウは中心座標が載っているペインへ自動で入ります。新規ウィンドウは直前フォーカスのペインを継承します。すでに割り当て済みならそのままです。

同じペインに複数ある場合は重ねて配置し、そのペインのスイッチャーで前面を切り替えます。ペインへ入れるための追加キーはありません。

現在のレイアウトはメニューバーの Division アイコンからも選べます。

上下方向（`j` / `k`）はキーとして受け付けますが、v1 のレイアウトはすべて縦カラム分割のため、隣接ペインがなく何もしません。

### スイッチャー

`opt+tab` でフローティングパネルが開きます。**今フォーカスしているウィンドウと同じペイン**に割り当てられたウィンドウが、そのペイン内の順で並びます。その後ろに、このスペース上で **どのペインにもまだ割り当てられていない** ウィンドウが、アプリ名とタイトルの順で続きます。番号（1, 2, 10…）もその一覧の番号です。

別ペインにすでに割り当てられているウィンドウは出しません（スペース全体の Alt-Tab ではありません）。他ペインへは `cmd+opt+hjkl` でフォーカス、`cmd+opt+shift+hjkl` でウィンドウ自体を移します。

今のペインが空でも、未割り当てウィンドウがあれば候補に出るので、そこから選んでこのペインに入れられます。未割り当て行を確定すると、そのウィンドウをこのペインに割り当ててタイルし、前面にします。

フォーカス中のウィンドウが未割り当てのときは、そのウィンドウ中心が載っているペイン（不明なら `defaultPane`）の一覧を出します。

- 番号を入力すると、その数字で始まる候補が絞り込まれてハイライトされます（`1` なら 1, 10, 11…）
- `Enter` でハイライト中のウィンドウを最前面にして閉じます。数字が一つに定まっても、確定には `Enter` が必要です
- 入力が空のまま `Enter` を押すと、ハイライト行（初期状態は先頭）を確定します
- 該当しない番号で `Enter` を押してもパネルは閉じません
- `Backspace` で入力した数字を 1 桁消し、`↑` / `↓` で現在の候補間を移動します
- `Esc`、またはスイッチャーホットキーをもう一度押すとキャンセルして閉じます
- すでにこのペインに割り当て済みの行だけ、ドラッグして並べ替えられます。未割り当て行は選択できますが並べ替え対象ではありません。並べ替え後、番号は新しい順に更新されます

## 設定

設定ファイルは `~/.config/division/config.json` です。ファイルがない場合はデフォルト設定を使用します。

```json
{
  "modifier": "cmd+opt",
  "switcher": "opt+tab",
  "keys": {
    "focusLeft": "h",
    "focusDown": "j",
    "focusUp": "k",
    "focusRight": "l",
    "cycleLayout": "tab"
  },
  "defaultLayout": "half",
  "defaultPane": 0
}
```

- `modifier`: フォーカス・移動・レイアウト循環に付く修飾キー。`cmd` / `command` / `ctrl` / `control` / `opt` / `option` / `alt` / `shift` を `+` で組み合わせます。スイッチャーには使いません
- `switcher`: スイッチャーのフルホットキー（デフォルト `opt+tab`）。修飾キーは `modifier` と独立です
- `keys.focusLeft` など: フォーカス移動と、同じキーに `shift` を付けたウィンドウ移動のキー
- `keys.cycleLayout`: `modifier` と組み合わせてレイアウトを循環するキー（デフォルト `tab` → `cmd+opt+tab`）
- `keys.switcher`: 旧設定用。トップレベルの `switcher` が無いときだけ `modifier` + このキーにフォールバックします（例: `"s"` → `cmd+opt+s`）
- `defaultLayout`: `half`（1:1）、`oneTwo`（1:2）、`twoOne`（2:1）、`thirds`（1:1:1）
- `defaultPane`: 直前フォーカスが未割り当てのときに、新規ウィンドウが落ちるペイン（左から 0 始まり）

既存の `~/.config/division/config.json` がファイルとして存在すると、その内容がデフォルトより優先されます。`keys.switcher` だけ書いて `switcher` が無い古いファイルは `cmd+opt+s` のままです。新デフォルトの `opt+tab` にするには、`"switcher": "opt+tab"` を足すか該当キーを消して Reload Config してください。Division はユーザーの設定ファイルを自動では上書きしません。

設定の変更は、メニューバーから Reload Config を選ぶか、アプリを再起動すると反映されます。

スペースごとのレイアウト選択は `~/.config/division/state.json` に保存されます。ウィンドウのペイン割り当てはウィンドウ ID がセッション依存のため、アプリ終了後は保持しません。

## 新規ウィンドウの割り当て

新しく標準ウィンドウが開くと、その直前にフォーカスしていた割り当て済みウィンドウと同じペインへ自動割り当てされます。直前フォーカスが未割り当てだった場合は `defaultPane` へフォールバックします。Division 起動時やスペース切替時にすでに開いていたウィンドウは、中心座標が載っているペインへ自動割り当てされます。
